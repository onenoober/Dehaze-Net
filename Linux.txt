DEA-Net Ubuntu 22.04 server command notes
=========================================

适用场景：
- 云服务器系统：Ubuntu 22.04
- 当前登录用户示例：root
- 建议工作目录：/root/workspace/Dehaze-Net
- 本文件只记录常用命令和注意事项，数据集、权重下载入口见 docs/DOWNLOADS.md


快速流程：按你当前 Ubuntu 22.04 服务器从零执行
------------------------------------------------

下面这一套是最推荐的执行顺序。先照着跑，能跑通后再做结构改进。

第一步：确认当前位置并进入工作目录。

    pwd
    cd /root/workspace

第二步：安装基础工具。

    apt update
    apt install -y git unzip zip wget curl aria2 rsync tmux htop p7zip-full

第三步：拉取私有仓库代码。

如果服务器已经配置 GitHub SSH key：

    cd /root/workspace
    git clone git@github.com:onenoober/Dehaze-Net.git
    cd Dehaze-Net

如果目录已经存在，就更新：

    cd /root/workspace/Dehaze-Net
    git pull --ff-only

第四步：创建数据、权重、下载和实验目录。

    cd /root/workspace/Dehaze-Net
    mkdir -p dataset/RESIDE/ITS dataset/RESIDE/OTS dataset/HAZE4K
    mkdir -p trained_models/ITS trained_models/OTS trained_models/HAZE4K
    mkdir -p downloads experiment

第五步：创建兼容软链接。

说明：
- `train.py` 默认读 `dataset/RESIDE/ITS`
- `eval.py` 默认读 `dataset/ITS`
- 所以要创建软链接，避免复制两份数据浪费空间。

    cd /root/workspace/Dehaze-Net
    ln -sfn RESIDE/ITS dataset/ITS
    ln -sfn RESIDE/OTS dataset/OTS
    ls -lah dataset

第六步：准备数据集和 checkpoint。

下载入口看：

    cat docs/DOWNLOADS.md

如果你已经在本地或 U 盘下载好了压缩包，推荐从 Windows PowerShell 上传：

    scp E:\DehazeDownloads\ITS.zip root@服务器IP:/root/workspace/Dehaze-Net/downloads/
    scp E:\DehazeDownloads\OTS.zip root@服务器IP:/root/workspace/Dehaze-Net/downloads/
    scp E:\DehazeDownloads\HAZE4K.zip root@服务器IP:/root/workspace/Dehaze-Net/downloads/
    scp E:\DehazeDownloads\weights.zip root@服务器IP:/root/workspace/Dehaze-Net/downloads/

如果服务器能直接下载，用 aria2c：

    cd /root/workspace/Dehaze-Net/downloads
    aria2c -x 16 -s 16 -c "下载链接"

第七步：解压数据集。

先看压缩包内部结构：

    cd /root/workspace/Dehaze-Net
    unzip -l downloads/ITS.zip | head -50

如果压缩包里直接是 train/test：

    unzip downloads/ITS.zip -d dataset/RESIDE/ITS

如果压缩包里已经自带 ITS 目录，解压后检查是否多套了一层。目标结构应是：

    dataset/RESIDE/ITS/train/hazy
    dataset/RESIDE/ITS/train/clear
    dataset/RESIDE/ITS/test/hazy
    dataset/RESIDE/ITS/test/clear

检查：

    find dataset/RESIDE/ITS -maxdepth 3 -type d | sort | head -50

OTS 和 HAZE4K 同理：

    unzip downloads/OTS.zip -d dataset/RESIDE/OTS
    unzip downloads/HAZE4K.zip -d dataset/HAZE4K

第八步：放置 checkpoint。

权重最终应放在：

    trained_models/ITS/
    trained_models/OTS/
    trained_models/HAZE4K/

检查：

    find trained_models -type f

第九步：创建 Python 环境。

先不要盲目安装 DEA-Net 官方的 PyTorch 1.10。RTX 5090 很新，旧 PyTorch 可能不支持。
优先使用能支持新 GPU 的 PyTorch CUDA 12.8 轮子。

    conda create -n deanet python=3.10 -y
    conda activate deanet
    python -m pip install --upgrade pip
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
    pip install -r requirements.txt

检查 PyTorch 和 GPU：

    python - <<'PY'
    import torch
    print("torch:", torch.__version__)
    print("cuda version:", torch.version.cuda)
    print("cuda available:", torch.cuda.is_available())
    if torch.cuda.is_available():
        print("gpu:", torch.cuda.get_device_name(0))
    PY

如果 `cuda available` 是 False，先不要训练，说明 PyTorch / CUDA / 驱动还没对上。

第十步：先跑 checkpoint 测试，不要一上来训练。

    cd /root/workspace/Dehaze-Net/code
    conda activate deanet
    python eval.py --dataset ITS --model_name DEA-Net-CR --pre_trained_model PSNR4131_SSIM9945.pth

如果测试 OTS：

    python eval.py --dataset OTS --model_name DEA-Net-CR --pre_trained_model PSNR3659_SSIM9897.pth

如果测试 HAZE4K，把文件名换成实际下载到的 HAZE4K 权重名：

    python eval.py --dataset HAZE4K --model_name DEA-Net-CR --pre_trained_model 实际HAZE4K权重文件名.pth

第十一步：跑小训练 smoke test。

先确认训练流程能启动、能前向、能保存模型：

    cd /root/workspace/Dehaze-Net/code
    conda activate deanet
    python train.py --epochs 1 --iters_per_epoch 10 --finer_eval_step 10 --w_loss_L1 1.0 --w_loss_CR 0.1 --start_lr 0.0001 --end_lr 0.000001 --exp_dir ../experiment/ --model_name smoke-test --dataset ITS

如果提示 `experiment/ITS/smoke-test has already existed`，换名字：

    --model_name smoke-test-v2

第十二步：跑完整训练。

建议用 tmux，断开 SSH 也不会停：

    tmux new -s deanet
    cd /root/workspace/Dehaze-Net/code
    conda activate deanet
    python train.py --epochs 300 --iters_per_epoch 5000 --finer_eval_step 1400000 --w_loss_L1 1.0 --w_loss_CR 0.1 --start_lr 0.0001 --end_lr 0.000001 --exp_dir ../experiment/ --model_name DEA-Net-CR-ITS-baseline --dataset ITS

退出 tmux 但保持训练运行：

    Ctrl+B 然后按 D

重新进入：

    tmux attach -t deanet

第十三步：查看训练状态。

看 GPU：

    nvidia-smi

实时看 GPU：

    watch -n 1 nvidia-smi

看实验输出：

    cd /root/workspace/Dehaze-Net
    find experiment -maxdepth 4 -type d | sort | head -100
    find experiment -name "*.pk" -o -name "*.pth"

第十四步：如果下载慢。

apt 慢：
- 换清华源或阿里源，之前你已经换成清华源，速度正常。

数据集慢：
- 百度网盘优先本地客户端下载到 U 盘。
- 再用 scp 上传到服务器。
- 不建议在服务器上硬等百度网盘/Google Drive/Dropbox。

第十五步：第一次最小目标。

不要一开始就下载全部数据。推荐顺序：

    1. 先准备 ITS test + ITS checkpoint
    2. 跑通 eval.py
    3. 再准备 ITS train
    4. 跑 smoke-test
    5. 再跑完整 ITS baseline
    6. 最后补 OTS / HAZE4K


0. 新手先看：路径和终端小坑
---------------------------

查看当前所在目录：

    pwd

进入工作目录：

    cd /root/workspace

注意：
- `~` 表示当前用户的 home 目录。root 用户下，`~` 就是 `/root`。
- 如果你在 `/root/workspace` 里执行 `mkdir -p ~/Dehaze-Net`，实际创建的是 `/root/Dehaze-Net`，不是 `/root/workspace/Dehaze-Net`。
- 建议统一使用 `/root/workspace/Dehaze-Net`，后面命令都按这个目录写。

如果终端里出现类似 `cd ^[[200~`：
- 这是复制粘贴时带进来的特殊控制字符。
- 按 `Ctrl+C` 清空当前输入，再重新手动输入命令即可。
- 不要把 `^[[200~` 当作目录名。

5. 从 Windows / U 盘上传数据到服务器
------------------------------------

下面命令在 Windows PowerShell 执行，不是在服务器里执行。

假设：
- U 盘路径：E:\DehazeDownloads
- 服务器 IP：SERVER_IP
- 服务器用户：root
- 服务器项目目录：/root/workspace/Dehaze-Net

上传压缩包到服务器：

    scp E:\DehazeDownloads\ITS.zip root@SERVER_IP:/root/workspace/Dehaze-Net/downloads/
    scp E:\DehazeDownloads\OTS.zip root@SERVER_IP:/root/workspace/Dehaze-Net/downloads/
    scp E:\DehazeDownloads\HAZE4K.zip root@SERVER_IP:/root/workspace/Dehaze-Net/downloads/
    scp E:\DehazeDownloads\weights.zip root@SERVER_IP:/root/workspace/Dehaze-Net/downloads/

如果是文件夹：

    scp -r E:\DehazeDownloads\trained_models root@SERVER_IP:/root/workspace/Dehaze-Net/

大文件更推荐用 rsync，支持断点续传：

    rsync -avP E:\DehazeDownloads\ITS.zip root@SERVER_IP:/root/workspace/Dehaze-Net/downloads/

如果 Windows 没有 rsync，先用 scp 即可。


5.1 直接在服务器下载（如果链接支持）
------------------------------------

如果数据源在服务器上能直连，优先直接下载到服务器，省去本地中转：

    cd /root/workspace/Dehaze-Net/downloads
    wget -c "下载链接" -O file.zip

或者用 aria2c，多线程更稳：

    aria2c -x 16 -s 16 -c "下载链接" -d /root/workspace/Dehaze-Net/downloads -o file.zip

如果是 Google Drive，并且链接稳定，可先安装 gdown：

    python -m pip install gdown
    gdown "Google Drive 分享链接" -O /root/workspace/Dehaze-Net/downloads/file.zip

如果是百度网盘：
- 有些链接可以直接在服务器浏览器里打开下载。
- 如果没有浏览器，优先看 docs/DOWNLOADS.md 里的百度盘入口和兜底方案。


6. 在服务器上解压数据
---------------------

先查看压缩包内容，不要急着解压：

    cd /root/workspace/Dehaze-Net
    unzip -l downloads/ITS.zip | head -50

如果压缩包里面直接是 `train/` 和 `test/`：

    unzip downloads/ITS.zip -d dataset/RESIDE/ITS

如果压缩包里面已经包含 `ITS/train`、`ITS/test` 这种上层目录，解压后可能会多一层目录。
解压后一定检查：

    find dataset/RESIDE/ITS -maxdepth 3 -type d | sort | head -50

期望结构大概是：

    dataset/RESIDE/ITS/train/hazy
    dataset/RESIDE/ITS/train/clear
    dataset/RESIDE/ITS/test/hazy
    dataset/RESIDE/ITS/test/clear

OTS 示例：

    unzip downloads/OTS.zip -d dataset/RESIDE/OTS
    find dataset/RESIDE/OTS -maxdepth 3 -type d | sort | head -50

HAZE4K 示例：

    unzip downloads/HAZE4K.zip -d dataset/HAZE4K
    find dataset/HAZE4K -maxdepth 3 -type d | sort | head -50

如果解压出错，可能是 `.rar`、`.7z` 或分卷压缩包，需要安装对应工具：

    apt install -y p7zip-full unrar

然后：

    7z x downloads/文件名.7z -odataset/目标目录
    unrar x downloads/文件名.rar dataset/目标目录/

10. 训练：运行 DEA-Net baseline
------------------------------

进入代码目录：

    cd /root/workspace/Dehaze-Net/code

官方训练命令：

    python train.py --epochs 300 --iters_per_epoch 5000 --finer_eval_step 1400000 --w_loss_L1 1.0 --w_loss_CR 0.1 --start_lr 0.0001 --end_lr 0.000001 --exp_dir ../experiment/ --model_name DEA-Net-CR-ITS-baseline --dataset ITS

新手先跑一个小规模 smoke test，确认流程能跑通：

    python train.py --epochs 1 --iters_per_epoch 10 --finer_eval_step 10 --w_loss_L1 1.0 --w_loss_CR 0.1 --start_lr 0.0001 --end_lr 0.000001 --exp_dir ../experiment/ --model_name smoke-test --dataset ITS

注意：
- 当前 `code/train.py` 写死了训练数据路径：`../dataset/RESIDE/ITS/train`。
- 当前 `--dataset` 参数主要影响实验目录名，不会自动切换 OTS / HAZE4K 训练数据。
- 当前 `code/train.py` 的 DataLoader 里 batch size 也写死为 16，`--bs` 参数没有真正用上。
- 如果显存不够，需要改 `code/train.py` 里的 `batch_size=16`。

14. 常见报错和处理
------------------

1) ModuleNotFoundError

说明缺 Python 包。先确认环境：

    conda activate deanet
    pip install -r requirements.txt

如果缺某个包：

    pip install 包名

2) CUDA out of memory

说明显存不够。优先做这些：
- 改小 `code/train.py` 里的 batch_size。
- 先跑 smoke test。
- 确认没有其他训练进程占显存：

    nvidia-smi

3) FileNotFoundError: dataset

检查目录：

    ls -lah /root/workspace/Dehaze-Net/dataset
    find /root/workspace/Dehaze-Net/dataset -maxdepth 4 -type d | sort | head -100

4) FileNotFoundError: checkpoint

检查权重路径：

    find /root/workspace/Dehaze-Net/trained_models -type f

5) 实验目录已存在后程序直接退出

`code/option_train.py` 里如果 `model_name` 对应目录已经存在，会直接退出。
解决办法：换一个新的 `--model_name`，例如：

    --model_name DEA-Net-CR-ITS-baseline-v2

6) OTS 指标和论文不一致

上游 README 提醒：OTS JPEG 输入对 Pillow 版本敏感。
如果要严格复现 OTS，可能需要 Pillow 8.3.2。
